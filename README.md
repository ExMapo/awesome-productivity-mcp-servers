Fork this repository and open a pull request.

```text

Official or Community:
Description:
```

Use this listing format:

```markdown

```

---

# ✅ Submission Guidelines

Before submitting an MCP server, make sure:

1. It supports or is designed for the **Model Context Protocol**.
2. It has a working public repository, documentation page, or official website.
3. It provides a useful productivity-related use case.
4. The description is concise and factual.
5. The project is not primarily spam or affiliate content.
6. Links are working.
7. The project is added to the most appropriate category.
8. Entries are added **alphabetically within each category**.

Official and community projects are both welcome.
